家長引導與技術

家長是陪玩的引導者；網頁是離線、不存資料的單純網頁。

每關的家長小卡

每關有一張可以收合的小卡，內容包括：

  1. 這關在學什麼：一句話說明學習重點。
  2. 可以問孩子的一句話：例如「為什麼要先看地上有沒有玻璃？」
  3. 孩子卡住時怎麼提示：先給線索，不直接說答案。
  4. 真實生活的延伸：例如一起固定家裡的高櫃、檢查防災包、實際走一次到集結點的路線。

技術規劃

項目做法
頁面獨立頁面，不放進原本的作文工具
技術只用 HTML、CSS、原生 JavaScript；不用框架、不裝套件、不載入外部資源
資料任務、裝備、單字放在獨立的資料檔，雙擊就能離線開啟
隱私不儲存任何資料、不蒐集個資、不使用麥克風
圖像用 CSS 與向量圖繪製，不使用外部圖檔
測試檢查資料完整：每件裝備都有英文與音節、每關都有家長小卡
