# 家園救援任務｜防災探索隊

親子防災教育互動遊戲（六個任務）與設計規劃網站。

- 互動遊戲在 `game/`：原生 HTML、CSS、JavaScript，離線可用；本機只儲存設定與勾選進度，不儲存姓名、住址、電話，不上傳。
- 說明網站：定位與界線、九個任務、英文與發音、孩子的建議、家長引導與技術、教材來源、決策與下一步（`node` 腳本從 `game/data.js` 產生，內容與遊戲一致）。
- 測試：`node tests/check.js`（資料與兒童防災安全規則）；`tests/e2e.html`（用 http 伺服器開啟，在瀏覽器真的點完六關）。
- 這是防災教育模擬，不是正式救護訓練，沒有獲得任何機關認證；內容整理自公開資料，請看教材來源頁的核對狀態。
- 原創設計，與任何遊戲公司無關；不含孩子或家庭的個人資料。
