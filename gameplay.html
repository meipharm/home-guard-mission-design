遊戲流程與任務

孩子用第一人稱扮演救援隊員：平日先整備，再進行重大災難演習。每一步都由自己選擇「我要做什麼」。

整體流程

  1. 居家安全檢查
  2. 防災包整備
  3. 家庭集結點
  4. 演習：地震防護
  5. 演習：戰時受傷止血
  6. 我們家的防災卡

第一人稱畫面

  • 像戴著頭盔看出去：上方是任務目標與時間，左下是背包欄位，右下是無線電對話框。
  • 場景用網頁內建的 CSS 與向量圖畫（房間、小鎮地圖、腿部示意），不需要外部圖檔。
  • 互動方式：在房間裡找危險、在地圖上選集結點、選擇行動、點選止血帶位置、按住轉動絞棒。

平日整備與演習

範圍收斂為 3 個平日整備站和 2 個重大災難演習。演習會用到整備時準備的防災包和集結點：例如地震後要帶防災包走樓梯、走散時到集結點會合。

PREP-01

居家安全檢查

災難發生前，家就是你的基地。先巡一遍家裡，找出地震時可能傷人、或擋住逃生的地方。

  1. 巡視家裡
  2. 找出危險的地方
  3. 想好怎麼改善
  4. 確認開關與滅火器位置

新單字：fire extinguisher

PREP-02

防災包整備

大災難發生時，可能要馬上離開家，道路和通訊也可能中斷。防災包要平常就準備好，至少能撐 3 天，拿了就能走。

  1. 選一個雙肩背包
  2. 依四大類挑物品
  3. 檢查必備物品
  4. 放在全家都知道的地方
  5. 定期檢查效期

新單字：go bag

PREP-03

家庭集結點

大災難時，家人可能在不同地方，電話也可能打不通。平常就要約好在哪裡會合。

  1. 選第一集結點（家附近）
  2. 選第二集結點（較遠）
  3. 約好聯絡方式
  4. 走散時到集結點等

新單字：meeting point

DRILL-01

地震防護因應

演習情境：你在客廳寫功課，突然發生大地震，地面劇烈搖晃，櫃子上的東西開始掉下來！

  1. 趴下、掩護、穩住
  2. 搖完先穿鞋
  3. 注意瓦斯
  4. 帶防災包走樓梯
  5. 到集結點會合

新單字：earthquake drop cover hold on stairs

DRILL-02

戰時受傷止血

演習情境：防空警報響起，你和家人前往避難處所途中，家人的大腿被掉落的碎片劃傷，血一直湧出來，用力壓也壓不住。戰時救護車可能無法馬上趕到。

  1. 先到安全的地方
  2. 判斷：壓不住才用
  3. 綁在傷口上方
  4. 轉絞棒到不流血
  5. 固定、寫時間
  6. 不鬆開，通報救護

新單字：siren shelter bleeding tourniquet tighten twist lock

開始互動任務

緊急避難包清單 已參考來源整理

依臺北市政府消防局〈緊急避難包〉的四大類整理，並參考黑熊學院的極簡準備指南。遊戲中防災包有 14 格，孩子要先放「必備」，再用剩下的空間加帶「建議」物品；也有遊戲機、整箱泡麵等干擾物品，選了不扣分，檢查時再說明。

類別物品與用途
水和食物必備飲用水：至少 2 瓶（每瓶約 600 毫升）；可再加輕的水壺。
必備不用煮的主食：提供飽足感，例如罐頭、即食飯、米餅、口糧餅乾。
建議能量點心：快速補充熱量，例如營養棒、堅果、巧克力、糖果；喜歡的小零食也能安定心情。
衛生用品必備外傷藥膏與包紮用品：處理擦傷、割傷的基本包紮用品。
必備常用藥物與處方藥：家人每天要吃的處方藥，以及止痛、止瀉、過敏、感冒等常備藥。
建議口罩：避免吸入灰塵、煙霧，也能防疫。
建議衛生紙與濕紙巾：衛生紙、消毒濕紙巾或酒精，保持清潔；也可帶小條毛巾、生理用品（如有需要）。
生活防災用品必備手電筒或頭燈：停電、夜間照明；頭燈可以空出雙手。
必備備用電池：手電筒、收音機的電力。
必備哨子：受困時吹哨求救，比大喊省力、傳得遠。
必備可攜式收音機：停電、網路斷線時收聽官方消息；手搖發電款更不怕沒電。
必備輕便雨衣與外套：防風防雨、保暖；機車雨衣也可以。
必備紙本地圖與聯絡資訊：寫下家人電話、集結點和路線；手機沒電也看得到。
必備身分證、健保卡、存摺：證明身分、就醫、領錢；用夾鏈袋防水。
建議充飽的行動電源：幫手機充電，才能聯絡家人。
建議保暖毯或小型睡袋：晚上保暖，避免失溫。
建議工作手套：防切割、耐磨，清理碎玻璃或雜物時保護雙手。
建議紙筆：抄電話、留字條，也能寫下綁止血帶的時間。
建議夾鏈袋：幫證件、藥品防水，也能把物品分類。
照護用品建議家人照護用品：依家人需要準備：嬰兒奶粉尿布、寵物食品與牽繩、長輩的假牙清潔劑或助聽器電池等。
本遊戲另加建議止血帶：手或腳大量出血、壓不住時使用；要先受過訓練（演習二會用到）。
放在哪裡✓ 家門口附近
✓ 容易拿取的位置
✓ 全家人都知道的地方
✓ 也可以放在地震時會躲的桌子下
✗ 不要放在難以拿取的地方（例如櫃子最深處）
背包怎麼選用雙肩背包，空出雙手逃生
先用家裡舊背包就好，先求有再求好
避免戰術風格或迷彩背包，可能被誤認為民兵
準備亮色防水背包套，需要求救時比較容易被看見
原則上要能維持 3 天的基本需求，定期檢查效期並更換

「必備」與「建議」是本遊戲為孩子整理的優先順序，不是來源的分級；請依家人需要調整。來源：臺北市政府消防局〈緊急避難包〉、黑熊學院〈先求有再求好，準備避難背包不用花大錢：極簡準備指南〉。

家庭集結點

  1. 第一集結點：家附近的空曠處
  2. 第二集結點：較遠、全家都認得
  3. 外地聯絡人：電話打不通傳簡訊或用 1991 留言
  4. 到了集結點就留下來等

集結點要空曠、上方不會有東西掉下來；騎樓下、加油站都不適合。最後的「我們家的防災卡」會把集結點、聯絡人和防災包清單整理成一張，列印後貼在家裡。網頁不儲存填寫的內容，電話號碼列印後手寫。

止血帶步驟 草案，待官方核對

  1. 綁在傷口上方約 5 到 8 公分，避開關節；不確定位置時，綁「高且緊」。
  2. 拉緊帶子，貼好魔鬼氈。
  3. 轉絞棒，直到不再流血。
  4. 固定絞棒。
  5. 記下綁上的時間。
  6. 不要自己鬆開，等待救護人員。

完成後用無線電英文回報，例如 “Tourniquet on! Time 14:30.”

緊急避難包已依上方來源整理；地震、居家防災與集結點的內容仍要以官方資料（例如內政部《台灣全民安全指引》、消防署、紅十字會）核對後才寫進網頁。

犯錯時怎麼回饋

  • 不扣血、不出現失敗畫面；由「隊長」用無線電說明為什麼，再讓孩子重選。
  • 出血量條只用來表現急迫感，可以關掉。
  • 英文部分完全不計時。

任務覆盤

  • 三個問題：做對了什麼？哪一步要再想想？在真實的家裡會怎麼做？
  • 翻一張「遊戲 vs 現實」破解卡（見孩子的建議）。
  • 授予徽章，例如「安全偵察員」「止血專家」；不排名、不比分數。
  • 演習完成解鎖「Don’t worry, I’ve got you.」；平日整備完成解鎖「Be ready.」。
