遊戲流程與任務

孩子用第一人稱扮演救援隊員，從整備到完成任務，每一步都由自己選擇「我要做什麼」。

整體流程

  1. 任務簡報
  2. 整備室：整理避難包
  3. 任務關卡
  4. 任務覆盤
  5. 單字回顧
  6. 宣傳卡

第一人稱畫面

  • 像戴著頭盔看出去：上方是任務目標與時間，左下是背包欄位，右下是無線電對話框。
  • 場景用網頁內建的 CSS 與向量圖畫（雙手、止血帶、手臂示意），不需要外部圖檔。
  • 互動方式：選擇行動、點選位置（例如止血帶要綁在哪）、按住轉動絞棒。

整備室：整理避難包

  • 整理避難包就在整備室完成；任務中再實際用上這些裝備，兩者不重複。
  • 背包只有 6 格，要從 12 件物品裡挑，形成策略取捨。
  • 有干擾物品（遊戲機、零食）。選了不扣分，覆盤時問孩子：「這次有用到嗎？」
  • 任務中缺少某件裝備時，改用替代方案（沒有紗布就用乾淨的布），並說明原因。
  • 每張裝備卡有英文單字與發音，詳見英文與發音。

六個任務

原本規劃四個任務；孩子建議加入地震、防空與包紮後，擴充為六個。任務 1 原本是「整理避難包」，因為和整備室重複，改成「颱風停電夜」，練習實際用上避難包裡的裝備。

OP-01

颱風停電夜

強颱來襲的晚上，窗外風雨很大，家裡突然停電，四周一片漆黑。用你在整備室準備的裝備，帶家人度過這一夜。

  1. 拿出手電筒照明
  2. 不拿蠟燭走動
  3. 待在室內聽官方消息
  4. 走散就到集合點
  5. 受困吹哨求救

新單字：flashlight battery radio whistle

OP-02

地震應變

你在客廳寫功課，地面突然劇烈搖晃，櫃子上的東西開始掉下來！

  1. 趴下 Drop
  2. 掩護 Cover
  3. 穩住 Hold on
  4. 搖完先穿鞋
  5. 聞到瓦斯：不開燈、開窗離開

新單字：earthquake drop cover hold on

OP-03

防空警報

一陣長長的警報聲響起，廣播說這是防空警報。

  1. 聽到警報
  2. 跟大人到最近的避難處所
  3. 遠離窗戶、保護頭部
  4. 等官方宣布解除

新單字：siren shelter

OP-04

現場評估

家人在廚房打破玻璃杯，手被割傷，地上都是碎玻璃。

  1. 停下來看環境
  2. 穿鞋再靠近
  3. 叫大人、撥 119
  4. 說清楚地址和狀況
  5. 等對方先掛電話

新單字：safe help call

OP-05

簡易包紮

家人的手掌被割傷，一直流血。大人在旁邊，請你協助止血。

  1. 戴手套保護自己
  2. 紗布直接加壓
  3. 濕了再加一層
  4. 繃帶固定
  5. 檢查手指顏色

新單字：gloves gauze press bandage

OP-06

止血帶行動

家人的大腿被重物劃傷，血一直湧出來，用力壓也壓不住。大人已經撥了 119。

  1. 判斷：壓不住才用
  2. 綁在傷口上方
  3. 轉絞棒到不流血
  4. 固定絞棒
  5. 寫下時間
  6. 不鬆開，等救護

新單字：tourniquet tighten twist lock bleeding

開始互動任務

止血帶步驟 草案，待官方核對

  1. 綁在傷口上方約 5 到 8 公分，避開關節；不確定位置時，綁「高且緊」。
  2. 拉緊帶子，貼好魔鬼氈。
  3. 轉絞棒，直到不再流血。
  4. 固定絞棒。
  5. 記下綁上的時間。
  6. 不要自己鬆開，等待救護人員。

完成後用無線電英文回報，例如 “Tourniquet on! Time 14:30.”

地震、防空與包紮步驟同樣要以官方資料（例如內政部《台灣全民安全指引》、消防署、紅十字會）核對後才寫進網頁。

犯錯時怎麼回饋

  • 不扣血、不出現失敗畫面；由「隊長」用無線電說明為什麼，再讓孩子重選。
  • 出血量條只用來表現急迫感，可以關掉。
  • 英文部分完全不計時。

任務覆盤

  • 三個問題：做對了什麼？哪一步要再想想？在真實的家裡會怎麼做？
  • 翻一張「遊戲 vs 現實」破解卡（見孩子的建議）。
  • 授予徽章，例如「安全偵察員」「止血專家」；不排名、不比分數。
