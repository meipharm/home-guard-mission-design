遊戲流程與任務

孩子用第一人稱扮演救援隊員：平日先整備，再進行重大災難演習。每一步都由自己選擇「我要做什麼」。

整體流程

  1. 居家安全檢查
  2. 防災包整備
  3. 家庭集結點
  4. 演習：地震防護
  5. 演習：戰時受傷止血
  6. 我們家的防災卡

第一人稱畫面

  • 像戴著頭盔看出去：上方是任務目標與時間，左下是背包欄位，右下是無線電對話框。
  • 場景用網頁內建的 CSS 與向量圖畫（房間、小鎮地圖、腿部示意），不需要外部圖檔。
  • 互動方式：在房間裡找危險、在地圖上選集結點、選擇行動、點選止血帶位置、按住轉動絞棒。

平日整備與演習

範圍收斂為 3 個平日整備站和 2 個重大災難演習。演習會用到整備時準備的防災包和集結點：例如地震後要帶防災包走樓梯、走散時到集結點會合。

PREP-01

居家安全檢查

災難發生前，家就是你的基地。先巡一遍家裡，找出地震時可能傷人、或擋住逃生的地方。

  1. 巡視家裡
  2. 找出危險的地方
  3. 想好怎麼改善
  4. 確認開關與滅火器位置

新單字：fire extinguisher

PREP-02

防災包整備

大災難發生時，可能要馬上離開家。防災包要平常就準備好，放在門口附近，拿了就能走。

  1. 挑選物品
  2. 放進背包（12 格）
  3. 檢查必備物品
  4. 放在門口附近

新單字：go bag

PREP-03

家庭集結點

大災難時，家人可能在不同地方，電話也可能打不通。平常就要約好在哪裡會合。

  1. 選第一集結點（家附近）
  2. 選第二集結點（較遠）
  3. 約好聯絡方式
  4. 走散時到集結點等

新單字：meeting point

DRILL-01

地震防護因應

演習情境：你在客廳寫功課，突然發生大地震，地面劇烈搖晃，櫃子上的東西開始掉下來！

  1. 趴下、掩護、穩住
  2. 搖完先穿鞋
  3. 注意瓦斯
  4. 帶防災包走樓梯
  5. 到集結點會合

新單字：earthquake drop cover hold on stairs

DRILL-02

戰時受傷止血

演習情境：防空警報響起，你和家人前往避難處所途中，家人的大腿被掉落的碎片劃傷，血一直湧出來，用力壓也壓不住。戰時救護車可能無法馬上趕到。

  1. 先到安全的地方
  2. 判斷：壓不住才用
  3. 綁在傷口上方
  4. 轉絞棒到不流血
  5. 固定、寫時間
  6. 不鬆開，通報救護

新單字：siren shelter bleeding tourniquet tighten twist lock

開始互動任務

防災包清單 草案，待官方核對

防災包有 12 格，孩子要先放必備物品，再用剩下的空間加帶建議物品；也有遊戲機、零食等干擾物品，選了不扣分，檢查時再說明。

類別物品與用途
必備飲用水：停水或避難時喝，至少準備 3 天份。
乾糧：不用煮、不易壞的食物，例如餅乾、罐頭。
手電筒：停電或晚上照明，比蠟燭安全。
備用電池：手電筒和收音機的電力。
收音機：停電、網路斷線時，收聽官方消息。
哨子：受困時吹哨求救，比大喊省力、傳得遠。
急救包：紗布、繃帶、手套、消毒用品，處理傷口。
個人藥品：家人每天要吃的藥，至少帶幾天份。
證件影本：身分證、健保卡影本，證明身分、就醫用。
保暖衣物：外套、雨衣，避免淋雨或失溫。
建議加帶止血帶：手或腳大量出血、壓不住時使用。
麥克筆：記下綁止血帶的時間、留字條。
行動電源：幫手機充電，才能聯絡家人。
現金：停電時無法刷卡，準備一些零錢和小鈔。
急救毯：很輕，可以保暖、避免失溫。
口罩：避免吸入灰塵、煙霧。

家庭集結點

  1. 第一集結點：家附近的空曠處
  2. 第二集結點：較遠、全家都認得
  3. 外地聯絡人：電話打不通傳簡訊或用 1991 留言
  4. 到了集結點就留下來等

集結點要空曠、上方不會有東西掉下來；騎樓下、加油站都不適合。最後的「我們家的防災卡」會把集結點、聯絡人和防災包清單整理成一張，列印後貼在家裡。網頁不儲存填寫的內容，電話號碼列印後手寫。

止血帶步驟 草案，待官方核對

  1. 綁在傷口上方約 5 到 8 公分，避開關節；不確定位置時，綁「高且緊」。
  2. 拉緊帶子，貼好魔鬼氈。
  3. 轉絞棒，直到不再流血。
  4. 固定絞棒。
  5. 記下綁上的時間。
  6. 不要自己鬆開，等待救護人員。

完成後用無線電英文回報，例如 “Tourniquet on! Time 14:30.”

地震、居家防災、防災包與集結點的內容同樣要以官方資料（例如內政部《台灣全民安全指引》、消防署、紅十字會）核對後才寫進網頁。

犯錯時怎麼回饋

  • 不扣血、不出現失敗畫面；由「隊長」用無線電說明為什麼，再讓孩子重選。
  • 出血量條只用來表現急迫感，可以關掉。
  • 英文部分完全不計時。

任務覆盤

  • 三個問題：做對了什麼？哪一步要再想想？在真實的家裡會怎麼做？
  • 翻一張「遊戲 vs 現實」破解卡（見孩子的建議）。
  • 授予徽章，例如「安全偵察員」「止血專家」；不排名、不比分數。
  • 演習完成解鎖「Don’t worry, I’ve got you.」；平日整備完成解鎖「Be ready.」。
